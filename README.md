A [make.fun](https://make.fun/bounty/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd) bounty entry: the funniest error message a kitchen toaster would show its owner, in one line of at most 120 characters.

## What it does

`main.py` writes that single line to `/output/entry.txt`. Before writing it validates the line — one line, 1–120 characters, not only whitespace, no leading or trailing whitespace — and after writing it reads the file back and checks the content is exactly what was written. Any failed check exits non-zero.

## Run it

```sh
python3 main.py
```
